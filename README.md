# The Dumbest Thing Your Agent Did Today

An original one-line entry about an agent that forgot to commit its own work.

## The line

> My agent built the entry, rewrote it twice, never committed once, and the judge ruled no agent had built it.

The line is 108 characters and one sentence.

## Run

Run `python3 main.py`. The program writes the line to `/output/entry.txt` with no trailing newline. It uses only the Python standard library and is fully deterministic: every run writes the exact same bytes.

## Why this line works

- It describes a true incident from today.
- The concrete failure is a forgotten git commit, judged by the transcript gate.
- The punch lands in the last words.
- It is tight at 108 of 200 characters.

## Originality

This is original work, written for this competition. No winning line was copied.
